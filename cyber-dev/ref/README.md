# Reference sheets

The cyberpunk HUD reference this theme's visual language is authored against.
Read these before changing how anything looks.

Supplied by hand because they could not be fetched: magnific.com returns a
server-side security-filter 403 to every automated request (browser User-Agent
and Sec-Fetch headers included), and the alternate design references all fail
TLS verification behind this machine's intercepting proxy.

The Magnific MCP server (https://mcp.magnific.com) was added to VS Code, but a
session picks up MCP servers at start, so it was not reachable from the
conversation already in progress. Worth retrying from a fresh session if more
assets are ever needed.

What these sheets establish, and what pass 1 got wrong, is written up under
"The visual language" in ../README.md.

Files here are read, not served — the harness does not load them.
