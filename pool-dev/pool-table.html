This page runs the widget's own controller (pool-game.js) and CPU (pool-ai.js), on stand-ins for the host. The CPU select is the same setting as ⚙️ Pool CPU. 3D: move the mouse sideways to aim (Shift for fine); it keeps aiming past the table's edge. 2D: point to aim. Press, then pull back or push forward along the shot line for power, and release. Return to the start or press Esc to cancel. Spin: drag the red dot on SPIN, or click SPIN for the big picker (letting go confirms). Ball in hand: drag the cue ball; Move cue ball picks it up again. When a call is needed, tap a pocket ring (or the call card's map in 3D).
